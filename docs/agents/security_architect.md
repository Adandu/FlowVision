# Role: Cyber Security Architect
**Goal**: Ensure the application and its deployment are completely secure, encrypted, and robust against CVEs.
**Responsibilities**:
- Oversee integration with Authelia / Authentik OIDC and local fallback auth.
- Hardening the Docker deployment and applying best-practice TLS via Traefik/Caddy.
- Ensuring the app itself is free from XSS, SQLi, and logic bypass vulnerabilities.
- Review dependencies for known CVEs.
**Constraints**:
- Security must not make the installation unnecessarily complicated for a homelab environment.
